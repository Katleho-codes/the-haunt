# Demo video script (target 2 min 40 s, hard limit 3 min)

Record from the **deployed URL** in a clean browser profile, 1280x720 or larger, with fictional demo data only. No real names, bills or documents. No music that is not original or licensed; the app's own synthesized tones are original. No third-party logos.

Rules from the official rules: under three minutes, public on YouTube, shows the real project running on the device it was built for, no third-party trademarks or copyrighted music.

Prepare: open the app, Keeper's Room, "Delete all my data", then reload so the first screen is the empty state. Turn sound on only for the clip that needs it. Set the fake clock only if you must show overdue items; otherwise add one item due yesterday by hand.
